# 一键删除映射器

一个 macOS 按键映射工具：按下指定按键时执行一次 `⌘⌫`（Command-Delete）。默认触发键为 Caps Lock，可从列表选择其他按键，也可以捕获按键。

## 功能

- 选择或捕获触发键。
- 随时启用或暂停映射。
- 关闭悬浮窗口时退出应用，停止监听。

## 系统要求

- macOS 11 或更高版本。
- Xcode Command Line Tools（提供 `swiftc`）。

## 从源码构建

在 macOS 上运行：

```sh
./build.sh
```

生成的 App 位于 `build/一键删除映射器.app`。脚本使用本机 Swift 编译器构建，并进行 ad-hoc 签名；它不是 Developer ID 签名或公证版本。

## 首次使用

应用需要 macOS「辅助功能」权限来监听并发送按键事件。首次启动后，按系统提示在「系统设置 → 隐私与安全性 → 辅助功能」中授权；若授权状态没有更新，可在应用中点「重试授权」。

触发键会发送 `⌘⌫`。不同应用对该快捷键的处理不同：它可能删除选中的内容，也可能关闭标签页。请先确认当前应用中的快捷键行为，再选择触发键。

## 隐私

源码通过 macOS 事件接口监听键盘事件并发送映射后的按键；当前源码未包含网络请求代码。
